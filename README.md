# BF4 Portable for macOS

Исходный проект установки и запуска **легальной Windows-копии Battlefield 4** через Sikarugir Wine 11 и DXMT. Собственная игра и аккаунт EA обязательны. Это независимый проект, не связанный с EA, DICE, Apple или Sikarugir.

**Статус: кандидат v0.1.0-rc1.** Окончательный рецепт прошёл развёртывание из пустого каталога и хранилища, а новый ярлык открыл русское меню BF4 на тестовом Mac. Проверки всех сочетаний опций и запуск после настоящей перезагрузки Mac ещё не завершены. Смотрите [матрицу проверки](docs/VALIDATION.md). Успешный запуск прежней установки не подтверждает новую сборку. Репозиторий не содержит игры, авторизованного префикса или готовых сторонних бинарных компонентов.

Обычный путь: **распаковать → открыть Setup.command → войти в EA и установить BF4 → запускать ярлыком на рабочем столе**. Wine, DXMT, игровая совместимость, официальные игровые prerequisites и выбранные эффекты настраиваются автоматически. Консольные команды ниже нужны для дополнительных опций и диагностики.

## Что входит

- Воспроизводимый рецепт с закреплёнными официальными URL, commit и SHA-256.
- Исправления DXMT для запуска BF4: создание окна через Wine ExtEscape, инициализация рабочего стола, совместимость buffer RTV и безопасная обработка null RTV.
- Независимые опции ReShade/SweetFX, панели времени кадров и исправления боковых кнопок.
- Отдельный Wine-префикс, настройки пользователя и приложение **Battlefield 4 Portable.app** на рабочем столе.
- Русский, польский, английский и другие **установленные и доступные вашей лицензии** языки. Проект не скачивает неофициальные языковые пакеты.

## Требования

Целевая среда этого закреплённого комплекта: Apple Silicon, macOS **26 или новее**, Rosetta 2, Apple Command Line Tools (`xcode-select --install`), Python 3.9+ по `/usr/bin/python3`, curl, patch, Swift и SDK из CLT. Meson, Ninja, Wine SDK и LLVM-MinGW устанавливаются локально самим проектом. Homebrew не требуется.

Выбранный [KosmicKrisp Vulkan driver](https://docs.mesa3d.org/drivers/kosmickrisp.html), нужный Wine для обнаружения GPU/дисплеев, использует Metal 4 и требует macOS 26+. Требования самого Sikarugir мягче, но не описывают весь наш комплект. Прежняя рабочая установка была проверена на Apple M5 Pro / 24 ГБ / macOS 27.0.1. Результаты новой сборки перечислены отдельно в VALIDATION. macOS 26, другие Apple Silicon, Intel Mac и Boot Camp не проверены; прежние версии macOS этой конфигурацией не поддерживаются.

Нужны свободное место для вашей редакции BF4/DLC и примерно 6 ГБ для сборки и компонентов; при обычном копировании игры потребуется ещё одна полная копия. На APFS установщик сначала пробует copy-on-write клонирование игровых файлов. Нужен рабочий доступ к EA и серверам игры. Сетевые правила/VPN проект не изменяет.

Проверена Windows-копия, приобретённая в EA App / Origin. Цепочки Steam → EA и подписочные редакции здесь не проверены.

## Установка с нуля

1. Распакуйте исходный архив в новую папку. Не помещайте туда префикс или личные файлы.
2. Откройте `Setup.command` (если Finder блокирует неподписанный скачанный скрипт, используйте Terminal: `sh Setup.command`). При отсутствии CLT установщик откроет штатное окно Apple и дождётся установки; для Rosetta откроется штатный installer с условиями Apple. Подтверждения Apple выполняет пользователь. Сборка скачает проверенные компоненты; изменение содержимого по закреплённому URL приведёт к отказу, а не к выполнению непроверенного файла.
3. Установщик создаст **новый пустой префикс**, установит официальный закреплённый MSI-пакет EA App, создаст отдельный ярлык и откроет EA. Войдите **самостоятельно**. Проект не получает ваш пароль и не импортирует чужой сеанс. Пакет взят по URL из проверенного EA bootstrapper; SHA-256 MSI закреплён отдельно. Его служебная запись пакета создаётся только в новом Wine, чтобы избежать сбоя 32-битного диалога bootstrapper.
4. В EA установите BF4 в стандартную папку `C:\Program Files\EA Games\Battlefield 4`. Либо запустите `Manage.command` → `Copy legal game folder`: выберите папку с `bf4.exe`. Копируются только игровые файлы; старые ReShade/config/log файлы удаляются из новой копии. EA может потребовать Locate/Repair/загрузку метаданных и активацию. Копирование файлов не заменяет лицензию.
5. Запустите **Battlefield 4 Portable.app** на рабочем столе. DirectX и Visual C++ из вашей игры подготовятся автоматически при первом запуске или изменении пакетов prerequisites; повторный запуск их не переустанавливает. Для SweetFX/ReShade используется их 64-битный D3DCompiler 43. Если официальные установщики отсутствуют, восстановите BF4 в EA. При запросе PunkBuster используйте EA repair или официальный `pbsvc.exe` из игры.
6. Язык автоматически выбирается среди установленных пакетов по языку macOS; при отсутствии подходящего выбирается доступный английский или первый установленный пакет. В `Manage.command` → `Options` можно изменить язык и опции. Разрешите **Accessibility** приложению Battlefield 4 Portable при запросе macOS, если нужны боковые кнопки и F8/F9. Запись экрана для штатной работы не нужна.
7. EA завершает обновления/активацию; после этого запускается BF4. Сервер выбирайте в игре самостоятельно. Дальнейший запуск — одним кликом по ярлыку. Собственный вход, владение игрой и системные подтверждения невозможно заменить чужим готовым аккаунтом.

По умолчанию локальные данные находятся в `~/Library/Application Support/BF4 Portable`, за пределами Git. Можно выбрать пустое другое хранилище:

```sh
sh Setup.command --data-dir "/Volumes/Games/BF4 Private"
python3 -B src/bf4.py --data-dir "/Volumes/Games/BF4 Private" doctor
```

Для дальнейших команд используйте тот же `--data-dir` перед названием команды. Установленное приложение содержит исходники запуска и локальный указатель хранилища, поэтому после установки исходную папку можно переместить или удалить. Перемещение самого хранилища требует повторной генерации приложения через setup/update; это не перенос аккаунта между людьми.

## Язык, эффекты и FPS

`Manage.command` предлагает установленные языки и опции. При отсутствии нужного языка измените язык установки в EA и скачайте/восстановите официальный пакет, доступный купленной редакции. Не переименовывайте польские файлы в русские. После установки:

```sh
python3 -B src/bf4.py options --language ru_RU
python3 -B src/bf4.py options --reshade on --monitoring on
python3 -B src/bf4.py options --reshade off --monitoring off
```

Закройте игру перед изменениями: проект перезапускает **только свой** Wine-сеанс, чтобы новые опции были унаследованы EA и BF4. По умолчанию включены эффекты, панель, исправление мыши, MSync и ESync. **Настройки управления и графики создаёт сама BF4:** проект не создаёт PROFSAVE, не задаёт FOV, качество, разрешение или VSync и не переносит чужие привязки. Уже существующий профиль сохраняется. EA может предложить восстановить ваши собственные облачные сохранения; выбор делает владелец аккаунта.

Проект не устанавливает собственный лимит FPS при чистой установке. При желании задайте его явно: `python3 -B src/bf4.py options --fps-limit 400`. Это меняет только соответствующую строку `user.cfg`, сохраняя остальные команды; первоначальный файл резервно копируется локально. Ранее выбранный лимит сохраняется при обновлении. Высокий предел не гарантирует соответствующий FPS или отсутствие микрофризов.

Исправление мыши не обязательно. Оно проверено для Mouse 3/4 и боковых кнопок, отправляющих Cmd+[ / Cmd+]; остальные мыши и программы переназначения требуют своей проверки. Если ваши кнопки уже работают или нужен другой способ ввода, выключите `mouse_fix` в Options либо выполните `python3 -B src/bf4.py options --mouse-fix off`. Панель остаётся независимой. Помощник передаёт нажатия кнопок, а действия и привязки выбираются в самой BF4. Он не назначает карту, масштаб или другие действия за пользователя. При выключении помощник не преобразует боковые кнопки или Cmd+[ / Cmd+].

При включении ReShade скачивается официальный **6.8.0 без add-on**, SweetFX с его текстурами и заголовки ReShade. Рабочий адаптер использует **LumaSharpen → LiftGammaGain → Curves → Dither** с параметрами проверенного варианта. Четыре исходных функции извлекаются из официального SweetFX 1.5.1 и проверяются отдельными SHA-256; его старые injectors/DLL не используются и не распространяются. Современные SweetFX shaders остаются доступны для собственного пресета.

Пресет **применяется автоматически при запуске**. **F6** включает/выключает эффекты, **F7** открывает/закрывает меню ReShade; если клавиши Mac управляют мультимедиа, удерживайте **Fn**. Отдельная клавиша для «применения» при каждом запуске не нужна. Начальная конфигурация пропускает обучение ReShade; первоначальная загрузка эффектов может кратко показывать служебную надпись. Существующий пользовательский ReShade.ini сохраняет выбранные им клавиши.

Собственный совместимый ReShade-пресет импортируйте локально в папку игры и выберите в интерфейсе. Старые SweetFX 1.x presets не совместимы напрямую с ReShade 6: нужна разрешённая лицензией конверсия эффектов. Проект не распространяет чужие пресеты и не обещает универсальную конверсию. Оригинальная установка с вашим прежним пресетом сохраняется.

Начальный `PortableSweetFX.ini` создаётся один раз: повторный запуск и переключение опции не перезаписывают пользовательские изменения этого пресета или существующего `ReShade.ini`.

При включённых эффектах используется native D3DCompiler 43 из официального DirectX-пакета игры. Установщик задаёт этот выбор только для `bf4.exe`; EA и другие приложения его не наследуют. При выключении эффектов возвращаются builtin-компиляторы Wine. Библиотеки Microsoft не входят в публикуемый проект.

F8 сбрасывает статистику; нажимайте **после загрузки карты и появления персонажа**. F9 скрывает панель, но продолжает сбор. Полное отключение `--monitoring off` выключает запись Present и сбор статистики, сохраняя помощник мыши. Опциональный CSV включается в меню BF4 FPS и хранится только локально. [Метод и ограничения измерения](docs/MONITORING.md).

## Структура

```text
Setup.command / Manage.command / Launch.command
src/                     launcher, input helper, Present collector
scripts/                 reproducible build, privacy scan, source packaging
patches/dxmt-bf4.patch    LGPL DXMT compatibility + optional telemetry
assets/                  effect adapter and initial ReShade configuration
dependencies.lock.json   official URLs and SHA-256
docs/                    setup, evidence, licenses, limitations
licenses/                third-party notices
tests/                   integrity, statistics, isolation checks
```

Проектные исходники — MIT; изменения DXMT — LGPL-2.1-or-later. Лицензии сторонних компонентов сохраняются. Бинарные релизы Wine/Sikarugir/EA/ReShade и игровые файлы не включаются в публикуемый архив. Перед любым добавлением бинарных релизов нужно отдельно проверить право распространения и выполнить требования соответствующих лицензий.
