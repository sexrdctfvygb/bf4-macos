# Существующие проекты и выбор подхода

Проверка первичных источников: 2026-10-10. В просмотренных GitHub-проектах/инструкциях не найден полный установщик BF4 для Sikarugir Wine + DXMT с нашими исправлениями, независимым вводом и мониторингом. Это результат ограниченного поиска, не утверждение об отсутствии любых других решений.

Выбран узкий установочный проект поверх официального Wine и DXMT: повторно используются их компоненты и исходники, а собственная часть отвечает за чистый префикс, BF4 compatibility patch, ввод, запуск и измерение кадров. Нет нового Wine engine, копии Creator или попытки упаковать лицензию игры. Заимствования/источники изменений перечислены в DEPENDENCIES.

MIT-проект Titanfall 2 можно доработать для его цепочки Steam → EA, но он не сохраняет проверенный BF4 Wine 11 / DXMT стек и не содержит наш независимый ввод и измеритель Present. Поэтому он служит сравнением установки EA, а не основой копии его установщика. Его рекомендация DXMT + D3DCompiler для пустого входа EA сама по себе не доказала исправление в нашем новом префиксе.

Сторонние README и авторские сообщения подтверждают заявленные возможности, но не прохождение нашего сценария развёртывания. Подтверждение на целевом Mac хранится в VALIDATION, отдельно от этих заявлений.
