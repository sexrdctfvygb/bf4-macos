## Наблюдения, вошедшие в рецепт

EA в Wine-сеансе подготовки отображала пустое окно. Завершение только собственного сеанса перед запуском EA с закреплёнными CEF-параметрами показало вход / библиотеку и прошло холодные перезапуски. Порты EA не закреплены. Системные DNS, VPN и маршруты не менялись. Облачный конфликт может требовать собственного выбора владельца аккаунта; установщик не выбирает сохраняемые данные за него.

В серии тестовых перезапусков с полным завершением wineserver EA показала EC:10608 и предупредила о прерванной облачной синхронизации. Это ограничение тестового сценария: перед обычным изменением опций следует штатно выйти из BF4 и дождаться синхронизации. Повторное открытие игры не доказывает сохранность удалённой облачной копии; такой конфликт не разрешается установщиком автоматически.

Локальная ad-hoc пересборка меняла подпись app. TCC отвергал её по сохранённому cdhash, хотя прежний доступ был включён. Удаление только старого пункта Portable и добавление текущего app восстановило input tap; системное подтверждение выполнил пользователь. Затем он подтвердил физические карту/масштаб. Эта проверка Mouse 3/4 и Cmd+[ / Cmd+] не подтверждает любую другую мышь; исправление отключается независимо, игровые действия не назначаются установщиком.

При первом включении ReShade было чёрное окно, Present не поступал, компиляция остановилась на 24 из 28 файлов. Выбор native x64 D3DCompiler 43 из официальных redists игры вместо builtin 47 восстановил изображение; пользователь подтвердил серверную игру. Позже исправлено размещение трёх официальных текстур. Последний рабочий адаптер скомпилирован без ошибок; 43 загружен, 47 не загружен. Точный внутренний механизм первоначального зависания не установлен. Выбор компилятора ограничен bf4.exe и откатывается при выключении эффектов; Microsoft DLL не публикуется.

Рабочий адаптер выполняет LumaSharpen → LiftGammaGain → Curves → Dither в одном проходе. Его четыре header извлекаются из официального архива, а старые injectors и EXE не используются. Во время инициализации наблюдались многочисленные пересоздания ReShade runtime. В подтверждённой минуте активной серверной игры новых пересозданий и повторных компиляций не было; по этому наблюдению нельзя приписать игровую задержку компиляции.
