# Что измеряет панель

Источник: QPC-интервалы между **успешными DXGI Present** внутри BF4, записанные нашим патчем DXMT в атомарно подтверждаемое кольцо shared memory. Не время выполнения GPU, не завершение работы GPU и не фактический показ кадра дисплеем. Очередь и композитор могут менять соотношение этих событий. При лимите дисплея ниже FPS игры часть Present не становится отдельным показанным кадром.

| Показатель | Расчёт |
|---|---|
| FPS NOW | `1000 × n / sum(ms)` по последним до 120 принятым интервалам |
| AVG FPS | `1000 × N / sum(ms)` за текущий замер |
| 1% LOW | `1000 / mean` самых длинных `ceil(N × 0.01)` интервалов |
| 0,1% LOW | То же для `ceil(N × 0.001)` |
| Duration / frames | Сумма принятых интервалов / число интервалов, не время с запуска приложения |
| Max / long frames | Максимальный интервал и количество `>16.7`, `>33.3`, `>50 ms` |

LOW считается через гистограмму с округлением до 1 мкс, AVG/максимум/пороговые счётчики и CSV — по исходным QPC-интервалам. Это среднее медленной доли, **не обратная величина одного percentile**. 1% отображается начиная со 100 интервалов, 0,1% — с 1000; до 10000 интервалов 0,1% помечен предварительным.

Обновление панели — 4 раза/сек, независимо от кадров. Кольцо на 65536 записей не выполняет отдельную запись журнала на каждый кадр. Статистика хранит ограниченное окно истории и гистограмму; CSV выключен по умолчанию. Пропущенные/повреждённые записи помечают замер неполным. Это не гарантия нулевых накладных расходов; их проверяют сравнениями на одинаковой сцене.

Фоновые интервалы и переход фокуса исключаются по состоянию Wine/нативного помощника. Проверка фокуса имеет конечную частоту (примерно 50 мс у источника, 250 мс у помощника); переходы не являются точным покадровым датчиком активности. Меню и загрузка карты автоматически не распознаются. **F8 после появления персонажа** начинает игровой замер; не переключайте приложения в его ходе. Настоящие длинные кадры в непрерывном игровом интервале не отбрасываются и не ограничиваются сверху.

F9 меняет только видимость. `options --monitoring off` отключает сбор и источник Present при следующем запуске. Для кнопок мыши остаётся отдельная проверка процесса; она не считает кадры. Меню «Запись кадров в CSV» создаёт приватный файл. Не публикуйте эти файлы без отдельного обезличивания.
