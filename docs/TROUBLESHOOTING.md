# Ошибки и удаление

| Симптом | Действие |
|---|---|
| Скрипт не открывается Finder / quarantine | Проверьте источник архива, запустите `sh Setup.command` из Terminal. Не отключайте Gatekeeper/SIP глобально. App собирается локально и подписывается ad-hoc, Developer ID notarization отсутствует. |
| Нет Python/Swift/SDK | `xcode-select --install`, затем снова Setup. Python 3.9+ из CLT, `xcrun swiftc`. Не подменяйте системные файлы. |
| Download hash mismatch | Файл upstream изменился или загрузился неверно. Ничего непроверенного не выполняется; обновите проект с проверенным lock, не заменяйте hash автоматически. |
| Rosetta недоступна / bad CPU type | Установите Rosetta штатно на Apple Silicon. Wine engine x86_64; Intel compatibility отдельно не подтверждена. |
| Wine не показывает даже простые окна / не обнаруживает GPU | Проверьте `doctor` и свой `frameworks/vulkan/icd.d` manifest. Wine 11 использует Vulkan для display discovery, даже когда игра рендерит DXMT/Metal. Закреплённый KosmicKrisp требует macOS 26+. После восстановления компонентов остановите только свой Wine-сеанс и повторите запуск. |
| EA пустая / game pending | Запускатель готовит внутреннюю ссылку и службу EA, закрывает только свой Wine-сеанс подготовки, затем открывает EADesktop с `--in-process-gpu --log-level=1 --no-sandbox` первым Windows-приложением. Windows-помощник мыши стартует после обнаружения BF4. Эта последовательность прошла два холодных перезапуска; полный набор проверок смотрите в VALIDATION. `--no-sandbox` отключает Windows sandbox встроенного Chromium только в EA, как компромисс совместимости; диагностический TCP-порт не открывается. При сохранении ошибки выполните `doctor` и проверьте приватные журналы. Не используйте старый авторизованный префикс как исправление. |
| Ярлык висит до открытия EA | Сверьте версию исходников и повторно соберите app через update. Launcher обрабатывает события AppKit во время запуска дочернего процесса. Для пользовательского хранилища в Documents/Desktop macOS может запросить доступ к соответствующей папке; проверьте Files and Folders для Battlefield 4 Portable. Стандартное хранилище находится в Library/Application Support. |
| EA не видит скопированную игру | В новой EA App выберите установку/Locate/Repair в папку BF4 этого префикса. Дождитесь проверки. Метаданные content ID не заменяют entitlement/активацию. |
| EA: EC:10608 / прерванная облачная синхронизация | Такое окно наблюдалось при серии полных завершений Wine-сеанса. В проверенном предупреждении EA предлагает Cancel, ожидание пяти минут и повторный запуск; Launch Game предупреждает о возможной потере облачного сохранения. Не выбирайте замену/новое сохранение автоматически. Сохраните свои локальные данные приватно и самостоятельно решайте конфликт облака. Перед изменением опций штатно выйдите из BF4 и дождитесь окончания синхронизации EA. |
| Польский язык / нет ru_RU | `doctor` показывает реальные `.toc`. Получите официальный доступный пакет через EA; затем Options → language. Региональная лицензия может не иметь нужного языка. |
| DXMT crash / buffer RTV | Используйте закреплённый patched renderer; не смешивайте его PE DLL с другим native winemetal/shader. Сохраняйте приватный build-manifest для локального разбора. |
| Боковые кнопки приседают / не реагируют | Разрешите Accessibility именно текущему Battlefield 4 Portable.app; в macOS 27 этот раздел называется «Управление устройством и доступ к данным». После локальной пересборки ad-hoc подпись меняется: включённый старый пункт сам по себе не подтверждает доступ новой версии. Закройте игру, удалите только старый пункт Portable из этого списка и добавьте текущий app из своего хранилища, затем повторите запуск. Добавление поверх прежнего пункта в проверенном случае сохранило устаревшую подпись. Touch ID/пароль вводите самостоятельно в macOS. Проверяйте input_tap_enabled в приватном input-state.json. Исправление перехватывает Mouse 3/4 и Cmd+[ / Cmd+] только при активном BF4. Несовместимые mouse remappers могут требовать отдельной настройки. |
| Нет FPS панели | Monitoring on, активный BF4, F9 показать. Accessibility нужна для F8/F9. Проверяйте приватный input-state/stats, а не надпись «app running». При fullscreen overlay находится над Wine shielding level. |
| LOW мало / загрузка попала в AVG | После загрузки карты нажмите F8. Сравнивайте одинаковые участки; реальные долгие кадры не фильтруются. F9 только скрывает панель. |
| ReShade не включается | Проверьте owned dxgi.dll и app-specific Wine override, F7 (при необходимости Fn + F7) откройте overlay. Unmanaged dxgi.dll намеренно не перезаписывается. Legacy SweetFX 1.x требует совместимой конверсии. |
| Чёрный экран при загрузке SweetFX / сообщение про D3DCompiler 43 | Выполните `redists` для своего хранилища, затем снова включите ReShade через Options. Нужен native x64 D3DCompiler 43 из официального DirectX-пакета BF4; builtin Wine и библиотека от другого префикса не принимаются. Этот закреплённый рецепт выключает 47 только для bf4.exe, чтобы ReShade выбрал совместимый fallback 43. Не скачивайте DLL с посторонних сайтов. |
| Сетевые задержки / античит отключает | Транспорт и правила сервера диагностируются отдельно. Не обходите античит. Эта сборка не подтверждает поддержку всех серверов/версий античита. Shader/FPS overlay не доказывают здоровье сети. |
| После перезагрузки меню открывается, но подключение к серверу срывается | Это наблюдалось на тестовом Mac; после штатного выхода и запуска кнопкой «Играть» в EA App подключение заработало. Последующий повтор ярлыком с открытой EA тоже прошёл. Если ошибка повторяется, дождитесь окончания облачной синхронизации и попробуйте EA в том же префиксе. Помощник мыши и панель могут оставаться активными. Причина первого сбоя не установлена; работа всех серверов или устранение сетевой ошибки не гарантируются. |

`python3 -B src/bf4.py doctor` выводит факты о компонентах/опциях без аккаунта и полных локальных путей. Подробные Wine/EA журналы могут содержать личные сведения; не загружайте их в issue без отдельной очистки. Проект не отправляет телеметрию на сервер.

## Удаление

Закройте игру. `python3 -B src/bf4.py uninstall` остановит **только этот** Wine-сеанс и удалит собственный app/desktop link; prefix, игра, локальная авторизация и сохранения останутся.

Чтобы удалить и свои данные, сначала сохраните нужные save games приватно; затем выполните **осознанно** `python3 -B src/bf4.py uninstall --delete-data`. Это удаляет отмеченную маркером пользовательскую папку целиком. Для нестандартного хранилища добавьте его `--data-dir` перед командой. Удаление source checkout само по себе не удаляет игру и аккаунт.

Другие Wine-префиксы, старый ярлык и настройки сети не затрагиваются. Accessibility-разрешение ненужного app можно снять в macOS вручную.
