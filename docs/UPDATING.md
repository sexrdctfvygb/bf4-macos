# Обновление и откат

1. Закройте BF4 из этой сборки; не выполняйте обновление во время матча.
2. Сохраните **всё приватное хранилище**, включая prefix, config и сохранения, в приватное место. Проверяйте доступное место; prefix включает игровые файлы и авторизацию. Не добавляйте резервную копию в репозиторий или issue.
3. Получите новую проверенную версию source project и прочитайте её `dependencies.lock.json` / изменения лицензий. Схема данных пока v1; автоматической миграции между несовместимыми схемами нет.
4. Из source directory выполните `python3 -B src/bf4.py update` с тем же `--data-dir`, если он нестандартный. Команда останавливает только этот Wine-сеанс, сохраняет apps/renderer/wine/frameworks/tools в приватный `backups/<timestamp>`, пересобирает компоненты и обновляет app payload. Если сборка завершается ошибкой, эти пять каталогов восстанавливаются автоматически. **Это не полный откат prefix**: `wineboot -u` может изменить его файлы/реестр до последующей ошибки. Полную резервную копию из шага 2 сохраняйте до успешной проверки; при ошибке обновления prefix потребуется её ручное восстановление после остановки Wine. EA account и prefix не импортируются из другого места и не очищаются.
5. Проверьте `doctor`, повторный launch, язык, кнопки и свои опции. После пересборки локально подписанного app macOS может потребовать повторно разрешить Accessibility текущей версии; проверьте физические кнопки, даже если прежний пункт включён. Если изменение ухудшает поведение, закройте игру, выполните `stop` и восстановите все пять каталогов apps/renderer/wine/frameworks/tools из выбранной приватной backup. Настройки последнего изменения опций сохранены в `config.backup.json`; восстановите его как `config.json` и повторно примените согласованные опции.

Уже установленные аккаунты не входят в source update. EA App может обновляться самостоятельно; при новом запуске после остановки клиента launcher обнаруживает фактический EA version directory и обновляет собственную внутреннюю относительную ссылку и ImagePath **его собственной** службы. Уже работающий клиент повторно используется только в этом prefix. Папки старой EA версии не удаляются нашим кодом. IPC-порт службы выбирает EA; фиксированного порта в проекте нет.

Официальный EA installer имеет rolling URL. Если официальный файл изменился и не совпадает с закреплённым hash, установка остановится. Не отключайте проверку SHA-256. Обновление lock требует отдельно получить файл из официального источника, проверить происхождение/подпись, записать новый hash/version и повторить чистый setup/игровую матрицу. Замена Wine/DXMT/SDK/шаблона требует такого же повторного теста; native DLL/shader ABI взаимосвязаны.

Сборка не очищает shader cache для повышения FPS. Холодный запуск и прогретый повторный запуск могут различаться; сравнивайте их отдельно. Удалять старые экспериментальные cache/логи в чужих префиксах проект не умеет и не должен.
